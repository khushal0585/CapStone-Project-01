# Capstone Project 01

**📘 Data Analysis of NHANES Dataset**  
*An exploratory Python project analyzing health survey data using pandas and visualization tools.*

---

## 🚀 Project Overview

This project demonstrates the process of loading, cleaning, analyzing, and visualizing data from the NHANES dataset using Python. It explores health-related factors such as demographics, BMI, blood pressure, and lab measurements, then identifies trends and correlations.

---

## 🛠️ Contents

- `capstone1_converted.ipynb` — Fully functional Jupyter notebook with code and analysis  
- `capstone1.py` — Original Python script used to generate the notebook  
- `data1.csv`, `data2.csv` — Raw data files (e.g., demographics, lab results)  
- `README.md` — This documentation

---

## ⚙️ Environment & Installation

**Recommended setup using Python 3.8+**

1. Clone the repo:
   ```bash
   git clone https://github.com/khushal0585/CapStone-Project-01.git
   cd CapStone-Project-01
   ```
2. *(Optional but recommended)* Create and activate a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate    # macOS/Linux
   venv\Scripts\activate       # Windows
   ```
3. Install dependencies:
   ```bash
   pip install pandas matplotlib seaborn jupyter
   ```

---

## 📊 Usage Guide

1. Launch the notebook:
   ```bash
   jupyter notebook capstone1_converted.ipynb
   ```
2. Run the cells in sequence — the code:
   - Loads the provided CSV files into pandas DataFrames  
   - Cleans and merges data  
   - Performs exploratory analysis and computes statistics  
   - Produces visualizations (histograms, scatter plots, etc.)

3. Review findings and visual output inside the notebook.

---

## 🔍 Key Analysis Highlights

- Demographic distributions: gender, age groups
- BMI trends among participants
- Correlations between blood pressure and lab measurements
- Group comparisons (e.g., mean values across categories)

These are interpretatively commented within the notebook.
